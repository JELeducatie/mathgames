# Mathgames

Lesspellen wiskunde voor het digibord (CTOUCH): negatieve getallen, voorrangsregels, balansmethode en grafiek & formule.

Daarnaast een escaperoom met printbare opdrachtkaarten (map `escaperoom/`, zie `escaperoom/LEESMIJ.md`).

Online: https://jeleducatie.github.io/mathgames/

Leerlinggegevens (klassen, foto's, scores) worden alleen lokaal in de browser opgeslagen, niet in deze repository.
